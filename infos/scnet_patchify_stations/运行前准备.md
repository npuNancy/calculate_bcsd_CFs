## 2. 建立共享根与 ACL

由 1872 创建 **新的**运行目录，`umask 0002`。先保存相关目录 `getfacl -p`，确认文件系统支持 ACL 和跨节点 flock。祖先目录只需给 worker traverse；已有更高权限应保留，不能无条件把已有 rwx 条目降成 --x。仅在缺少权限时按所有者权限补齐 `/work/home/acjpoxgsdu`、`cf_stations` 的 traverse。

下例在 1872 上、确认 RUN_ID 是新目录后执行。WORKERS 从当前固定版本 accounts.csv 获取，不手工漏填：

```bash
SHARED_ROOT="/work/home/acjpoxgsdu/cf_stations/$RUN_ID"
mkdir -p "$SHARED_ROOT"
chmod 2770 "$SHARED_ROOT"
WORKERS=(acm83pfnji ac2k2a2td1 aczlvkl1ac acsep06cn2 acv2o7b0gn acbzycio4i ace4cjbrjf acmctdumnv acebblgpte acjp7am6kd acxujo26gv acavkyjhiz acdnwyi34a ac8svj4ybp)
setfacl -m 'u::rwx,g::rwx,m::rwx,o::---' "$SHARED_ROOT"
setfacl -d -m 'u::rwx,g::rwx,m::rwx,o::---' "$SHARED_ROOT"
for u in acjpoxgsdu "${WORKERS[@]}"; do
```

默认 ACL 必须包含 **具名 acjpoxgsdu**，这样 worker 创建的文件也可由汇总账号访问。目录默认 ACL 与 `umask 0002` 一起使用；普通文件不需要执行位。输出/runtime/index 目录在运行期间继续可写。账号目录祖先可达性、ACL mask 的 effective 权限必须逐个检查。

在专用 `runtime/acl_probe/` 中，让每个 worker 创建小文件、原子 rename；1872 读取并改写；另一个 worker 环形交叉读写。测试所有 worker 都能读取配置、源代表文件并写共享输出。用两个账号分别持有/尝试同一个 probe flock，验证第二个有界等待超时、释放后能够取得。只清理这些专用测试文件，不操作科学产物。检查计算节点挂载视图与登录节点一致（首个 prepare 作业亦验证）。

### 冻结时机

1. prepare 前只冻结人工输入 `inputs/campaign_config.json`、`inputs/release.json` 及独立来源证据；inputs 目录仍允许 prepare 创建文件。
2. prepare 成功后再冻结 `catalogs/`、`mappings/`、`prepared.json`、`inputs/station_cf_config.json`、`inputs/grid_cf_index.json`、`inputs/input_release.json`、`index/units.json`。目录所有需要读取的账号为 r-x，文件 r--，不再保留具名 worker 写权限；同时调整 default ACL，不能只 chmod 留下旧 ACL 写权限。
3. `index/` 本身需保持可写供 publish 使用，`outputs/`、`runtime/` 保持可写。记录 frozen 文件 SHA/stat，由程序后续校验。可写父目录仍允许删除/替换文件，因此只读文件 ACL 不是不可篡改保证；运行纪律与身份校验同时生效。
4. chmod/setfacl 必须由文件所有者或管理员执行。prepare 生成文件可能属于运行 prepare 的 worker；1872 的具名 rw 权限不授予更改其 ACL 的权限，应由该 worker 冻结自己的资产。不要递归 chmod 旧网格 CF 或其他运行目录。

## 4. 容量关卡

首先检查 1872 home 的个人额度、已用量、实际剩余与 inode；共享文件系统的 df 空闲不能当作个人可用额度。2026-10-01 的 df 约 16.09 PB 空闲只反映共享文件系统，quota 空输出也不能证明无配额。可以复用适用于该账号的既有用户/平台配额确认并注明日期，不重复询问已明确的信息。

prepare 前确认足够容纳目录、mapping、索引和日志。prepare 后以 `prepared.storage_estimate.raw_cf_bytes/year_nc_files` 为全量依据，结合压缩样本、临时文件、失败重试副本、元数据和至少 20% 安全余量，确认剩余空间不小于 `(预计新增结果+临时及失败开销)/0.8`。raw_cf_bytes 是 float32 逻辑量，不是压缩后体积上限；不能再次乘九或漏算三个 Station。生产年文件数量为 `8×非空unit数`，最多 27,072。若依赖压缩率才能装下，先限制提取并发完成代表样本再放量；不得为估算空间重新全量检查 BCSD。
